# Financial Data Dashboards

Two dashboards built with made-up sample data for practice and portfolio use. No real company data is included.

## 1. Loan Repayment Dashboard (Excel)
Tracks repayment rate, default rate and PAR 30 by branch, loan size and customer group.
- Tools: Excel, PivotTables, calculated fields, slicers
- Key findings: loans above ₦500k default at 15.8%; farmers default at 14.5%; Kano repays the least (79%)



## 2. Bank Profitability Dashboard (Power BI)
Compares 10 sample banks from 2019 to 2024 on ROA, ROE, cost to income and NPL ratio.
- Tools: Power BI, DAX measures
